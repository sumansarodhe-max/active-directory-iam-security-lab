# Active Directory IAM & Windows Security Lab

A hands-on cybersecurity lab demonstrating Identity and Access Management (IAM), Active Directory Domain Services (AD DS), Windows Server security, Group Policy, security groups, NTFS permissions, password policies, and account lockout controls.

## 🎯 Project Objective

The goal of this lab is to build and secure a Windows Active Directory environment and demonstrate practical IAM and Windows security concepts.

## 🛠️ Technologies Used

- Windows Server
- Active Directory Domain Services (AD DS)
- Active Directory Users and Computers (ADUC)
- Group Policy Management
- Security Groups
- NTFS Permissions
- Password Policies
- Account Lockout Policies
- Windows Security

## 🔐 Key IAM & Security Implementations

### 1. Active Directory Domain Services
- Configured Windows Server as a Domain Controller
- Created an Active Directory domain
- Managed users and organizational structure

### 2. User & Group Management
- Created user accounts
- Created security groups
- Assigned users to appropriate groups
- Applied role-based access principles

### 3. Group Policy
- Configured password policies
- Configured account lockout policies
- Applied security settings through Group Policy

### 4. NTFS Permissions
- Configured folder permissions
- Used security groups to manage access
- Demonstrated the principle of least privilege

### 5. Account Security
- Configured password requirements
- Configured account lockout thresholds
- Tested authentication and access controls
